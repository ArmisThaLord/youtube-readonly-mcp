# Agent instructions

This is a single-owner, read-only YouTube MCP server. Preserve read-only scopes and tools unless a maintainer explicitly requests otherwise. Never read, print, log, commit, or upload real tokens, .env files, or OAuth client secrets. Use mocks in tests. Do not commit dependency environments or generated files. Validate inputs and keep authentication fail-closed. Review Google API compatibility and run the test suite before proposing changes.
